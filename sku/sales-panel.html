Crear SKU VENTAS

14 caracteres · sin guiones

Producto (2) + categoría (2) + subcategoría (2) + clave (7) + sufijo (1).

Los SKU validados de la columna A se conservan. Los nuevos usan iniciales, omiten LA, LOS, EL, DEL y números, y completan la clave con ceros. Si una clave se repite, se asigna el primer sufijo libre: 0–9, A–Z. El módulo ID PDV se selecciona con las claves A01–A22 y se guarda como campo independiente del SKU.

CSV, TXT o TSV. Puedes incluir MODULO ID PDV como clave A01–A22 o nombre. Una columna de descripciones usa la clasificación del formulario. También puedes usar DESCRIPCION, PRODUCTO, CATEGORIA y SUBCATEGORIA. Las descripciones originales conservan sus números y artículos.
