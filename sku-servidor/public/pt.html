Configurar publicación · Familia / OneDrive · Solo Superadministrador

Selecciona carpeta sincronizada para usar Microsoft 365 Familia sin Client ID, o conserva la conexión Microsoft si ya tienes una aplicación registrada. Comparte las carpetas de destino como solo lectura para quienes consultan el Excel.

Primera conexión: obtener el Client ID
  1. En Microsoft Entra, registra una aplicación llamada GMP ERP PT que admita cuentas personales Microsoft.
  2. Habilita flujos de cliente público en Autenticación. Agrega permisos delegados de Microsoft Graph: User.Read y Files.ReadWrite. La conexión solicita offline_access para renovar la sesión.
  3. Copia el identificador de aplicación (Client ID). No necesitas crear ni pegar un secreto de cliente.
  4. Guarda la configuración aquí, pulsa Conectar con Microsoft y autoriza soportetecnico@grupomipan.com en la página oficial.

Sin Client ID: carpeta de OneDrive o PC puente

  1. En una PC Windows 11 instala OneDrive e inicia sesión con la cuenta propietaria de Microsoft 365 Familia.
  2. Crea una carpeta GMP_PT dentro de OneDrive y déjala disponible siempre en este dispositivo. Comparte esa carpeta en Windows con permiso de modificación para la cuenta de Windows que ejecuta GMP.
  3. En este formulario indica la ruta que el servidor puede abrir, por ejemplo \\PC-PUENTE\GMP_PT. Si GMP y OneDrive corren en la misma PC compatible, puedes usar su ruta local.
  4. Guarda y pulsa Probar carpeta. Activa la publicación automática. Mantén encendida la PC puente y OneDrive iniciado; comparte en la nube los archivos solo para lectura.

GMP confirma el guardado en la carpeta. OneDrive sincroniza después; verifica su icono y el archivo en la web. El guardado local no confirma que ya esté en la nube.
