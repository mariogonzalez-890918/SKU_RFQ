Conectar OneDrive personal · Solo Superadministrador

Autoriza la cuenta propietaria en Microsoft; GMP no solicita su contraseña. Comparte las carpetas de destino como solo lectura para quienes consultan el Excel.

Primera conexión: obtener el Client ID
  1. En Microsoft Entra, registra una aplicación llamada GMP ERP PT que admita cuentas personales Microsoft.
  2. Habilita flujos de cliente público en Autenticación. Agrega permisos delegados de Microsoft Graph: User.Read y Files.ReadWrite. La conexión solicita offline_access para renovar la sesión.
  3. Copia el identificador de aplicación (Client ID). No necesitas crear ni pegar un secreto de cliente.
  4. Guarda la configuración aquí, pulsa Conectar con Microsoft y autoriza soportetecnico@grupomipan.com en la página oficial.

Ejemplo: GMP_PT/EJIDOS/PT_EJIDOS_2026-11.xlsx. Son archivos generados para PT; el archivo de ejemplo existente se conserva.
